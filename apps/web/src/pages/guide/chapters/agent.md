# 小麦同学（对话）

小麦同学是工作区里的 AI 助手。它能读写项目文件、在画布上添加和连接节点、调用生图生视频、搜索网页，还会按「技能」里的方法一步步完成创作任务。

## 打开对话

进入项目后点右下角的小麦同学按钮。对话框可以悬浮，也可以停靠在右侧。顶部按钮：新建对话、历史对话、媒体生成控制。

## 怎么说话更好用

- **说清目标和要求**：“为这首歌做 8 个分镜，赛博朋克风，每个分镜出一张 16:9 的图”比“帮我做分镜”好得多。
- **@ 引用**：输入 @ 或点 @ 按钮，可以引用当前画布、其他画布或素材库里的内容，每条最多 20 个。
- **/ 技能**：输入 / 或点书本按钮，选择一个技能，例如 `/skill:workflow`，让它按指定流程工作。
- **附件**：可以直接发图片、视频、文档；也支持长按语音输入。
- **模型与思考强度**：输入框下方切换。复杂任务可以调高思考强度。

## 它在做事的时候

- 每一步调用工具（写文件、改画布、生成图片……）都会显示成一张「工具调用」卡片，可以展开查看。
- 生成过程中还能继续发文字：按 Enter 排队，等它做完这一步再看；按 Ctrl + Enter 立即引导它调整方向。
- 生成图片、视频、音频会扣费。点对话顶部的「媒体生成控制」，可以分别允许或禁止它生成图片、视频、音频。

## 让它更懂你

「设置 › 个性化」里：

- **麦麦工坊说明**：写给小麦同学的长期要求，比如“回答尽量简短”“默认用竖屏 9:16”。
- **本地记忆**：它会记住你的偏好，这里可以开关、查看和删除记忆。

## 让它学会新本事

- 装**技能**：教它新的工作流程，见「插件市场」和「技能开发」两章。
- 装**工具**：给它新的能力，例如联网搜索、操作浏览器。
- 接 **MCP**：把外部服务（文件系统、数据库、第三方 API）接给它用，见「MCP 接入」。
