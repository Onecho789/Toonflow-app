# 素材库与提示词库

## 素材库

素材库是全局的“收藏夹”，不属于任何一个项目。角色设定图、常用背景、满意的作品都可以放进去，在任意项目里随时取用。

**入口**：

- 左侧栏「素材库」（弹窗）
- 画布右侧侧栏的「资产」页签

**能做什么**：搜索、上传、新建文件夹、预览（双击也可以）、下载、移动、重命名、删除。在画布侧栏里可以把素材**插到画布中央**，或直接**拖进画布**变成节点。

**怎么放进去**：

- 生图、视频工作台的结果点「加入素材库」，分别进入「生图」「视频」文件夹
- 画布节点的更多菜单 →「保存到素材库」
- 在素材库里直接上传

和小麦同学对话时，用 @ 引用「全局素材」，就能让它使用素材库里的内容。

## 提示词库

提示词库收集了现成的优秀提示词和参考图，不知道怎么写提示词时就从这里挑。

**入口**：

- 生图、视频工作台提示词旁边的「提示词库」按钮
- 画布侧栏的「提示词库」页签，以及生成节点上的提示词库图标

选中一条后，提示词和参考图会自动带入，在此基础上改成你想要的内容即可。部分参考图来自海外网站，下载失败时请在「设置 › 网络设置」中配置代理。
