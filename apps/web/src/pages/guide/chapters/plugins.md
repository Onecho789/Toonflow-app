# 插件市场

插件让麦麦工坊变得更强：画布上多出新节点、小麦同学学会新技能、能打开更多类型的文件。左侧栏「插件市场」进入（也在「设置 › 插件市场」）。

## 插件有哪几种

| 类型 | 是什么 | 装好后在哪里用 |
| --- | --- | --- |
| 节点 | 画布上的新积木，例如一个新的生成器 | 画布的添加节点菜单 |
| 工具 | 小麦同学的新能力，例如联网搜索、操作浏览器 | 对话时它会自己调用 |
| 技能 | 一份写给小麦同学的“操作手册”，教它按某种方法做事 | 对话里输入 / 选择，或它按需自己读取 |
| 文件扩展 | 打开某类文件的查看器或编辑器 | 工作区「文档」面板里打开文件时 |
| Agent | 多个 AI 成员组成的团队 | 测试阶段，暂未开放 |

## 安装插件

**从市场安装**：「发现插件」页浏览、搜索，点安装即可。需要先登录麦麦云账号。喜欢的可以收藏，有新版本时按钮会显示「更新」。

**上传安装**：别人发给你的插件文件，点右上角「安装插件」选择文件。客户端会按文件名自动判断类型：

| 文件 | 类型 |
| --- | --- |
| `ext-名称.umd.js` | 文件扩展 |
| `名称.umd.js` | 节点 |
| `名称.tool.js` | 工具 |
| `SKILL.md`，或包含它的 `.zip` / `.tar` / `.tar.gz` / `.tgz` | 技能 |

单个文件最大 20 MB。只安装你信任的来源发来的插件：插件能读写你的工作区文件。

## 管理已安装的插件

「已安装」页可以按类型筛选，每个插件可以：

- **启用 / 停用**
- **配置**：有必填项没填时，配置按钮上会有红点，例如搜索工具需要填写 API Key
- **导出**：导出安装文件分享给别人
- **卸载**：内置的节点和工具不能卸载；内置技能和文件扩展可以

同名插件只有版本更高时才会覆盖。要重装同版本或降级，需要在「设置 › 开发者选项」里使用强制安装。

## 默认打开方式

同一种文件可能有多个文件扩展能打开（比如 `.md` 既能用文本编辑器，也能用 Markdown 预览）。

- 第一次打开时会让你选，可以设为默认
- 「默认打开方式」按钮里统一管理每种后缀用哪个扩展
- 在文件树里右键文件 →「打开方式」，可以临时换一个

## MCP 与 FFmpeg 页签

- **MCP**：把外部 MCP 服务接给小麦同学，见「MCP 接入」一章。
- **FFmpeg**：处理音视频（截帧、拼接、转码）需要的组件。点「下载并安装」一键装好，也可以改用电脑上已安装的版本。

## 技能放在哪

技能有两种安装位置：

- **全局**：从插件市场安装，所有项目都能用。
- **项目内**：把技能文件夹放到项目目录的 `skill/` 下，只在这个项目里生效。

两边有同名技能时，项目内的优先。想自己写一个技能，见「技能开发」。
