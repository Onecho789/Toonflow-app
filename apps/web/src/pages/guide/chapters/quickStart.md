# 快速上手

麦麦工坊是一个 AI 创作工作台：在无限画布上编排分镜，用生图、视频工作台直接出图出片，再让小麦同学帮你写脚本、搭流程。项目文件始终保存在你自己的电脑上，云端只负责账号、余额和模型。

## 三步开始

1. **登录**：打开客户端先看到「登录麦麦工坊」，用邮箱和密码登录。没有账号就点注册，填邮箱验证码，密码至少 8 位。首次登录需要先修改密码。
2. **充值**：生成图片、视频和对话都按用量扣费。左侧栏底部显示余额，点它进入「设置 › 账号」，再点「充值」。
3. **开始创作**：回到首页，选一个入口：

| 我想… | 去哪里 |
| --- | --- |
| 写一句话直接出图 | 首页「生成图片」或左侧「生图工作台」 |
| 用文字或图片生成视频 | 首页「生成视频」或左侧「视频工作台」 |
| 搭分镜、串流程、批量生成 | 左侧「无限画布」 |
| 让 AI 帮我规划整件事 | 首页输入框直接描述需求，交给小麦同学 |

## 首页输入框

在「今天要做点什么？」下面的输入框写下你的想法，例如“帮我做一个 30 秒的咖啡店宣传短片分镜”。

- **附件**：点回形针、拖入或粘贴。支持图片、视频、文档和代码文件，单个最大 100 MB，每条最多 20 个。
- **工作目录**：点左下角选择一个**空文件夹**。项目的画布、素材都会存在这里。
- **模型与思考强度**：点模型按钮切换。思考强度选 Default 表示由模型自己决定。
- **发送**：客户端会在目录里新建 `画布1.json`，进入工作区，并把你的描述交给小麦同学继续完成。

> 选的文件夹不是空的？那说明它已经是一个项目，请从「无限画布」页面打开它。

## 项目在哪里

左侧「无限画布」页面列出所有项目：

- **新建项目**：选空文件夹就新建；选已有项目的文件夹就直接打开。
- **打开**：点项目卡片。文件夹被移动或删除时会提示重新选择。
- **打包导出 ZIP**：把整个项目打成压缩包，方便备份或发给别人。
- **重命名 / 移除**：移除只是从列表里拿掉，**不会删除文件**。

## 遇到问题

- 左侧「问题反馈」可以提交 Bug、建议、插件或计费问题，客服会在里面回复你。
- 生成失败时先看余额，再看「设置 › 网络设置」：国内网络访问部分图片源需要代理。
