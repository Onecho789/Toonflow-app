# 生图工作台

不想搭画布，只想写一句话出图？用生图工作台。左侧栏「生图工作台」或首页「生成图片」进入。

## 第一次使用

点「选择文件夹」，选一个用来存放作品的文件夹，之后会自动记住。生成的图片保存在该文件夹的 `generated/` 下。

顶部的文件夹按钮可以「选择其他文件夹」。每个用过的文件夹都可以在文件管理器中打开、从列表移除（文件保留），或删除其中的作品。

## 出一张图

1. **写提示词**：描述画面内容、风格、光线和构图，越具体越好。没灵感就点旁边的「提示词库」，挑一个现成的。
2. **加参考图（可选）**：点「添加」，从本地上传、本文件夹作品或素材库选；也可以点「剪贴板」「上传」，或直接拖入、Ctrl + V 粘贴。能放几张由模型决定，不支持参考图的模型不会显示这一栏。
3. **选模型和参数**：

| 参数 | 说明 |
| --- | --- |
| 模型 | 不同模型擅长的风格、速度和价格不同 |
| 质量 | 自动 / 高 / 中 / 低，质量越高越慢、越贵 |
| 分辨率 / 比例 | 选「自动」时由模型决定；旁边会显示实际输出像素 |
| 透明背景 | 适合做贴纸、Logo、抠图素材（需要模型支持） |
| 数量 | 1–10 档，也可自定义（最多 20），**每张单独计费** |

4. 看一眼预估费用，点「生成 N 张图片」。

## 作品怎么处理

结果出现在右侧「生成结果」。每张图片可以：

- **预览、下载**
- **用作参考图**：在这张的基础上继续改
- **加入素材库**：进入素材库的「生图」文件夹，之后在画布里随时取用

「生成记录」里可以「回填参数」，一键还原当时的提示词和设置；失败的任务可以「重试」。

## 小技巧

- 先用低质量、少数量试方向，满意了再提高质量批量出图，省钱。
- 想要统一角色或风格，把满意的那张「用作参考图」再生成。
