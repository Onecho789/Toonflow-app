# 设置一览

左侧栏底部「设置」打开。

| 分组 | 能做什么 |
| --- | --- |
| 账号 | 查看麦麦云邮箱和余额，刷新、充值、退出登录 |
| 界面设置 | 语言、外观模式（浅色 / 深色 / 跟随系统）、背景样式、主题颜色、字体大小、圆角 |
| 常规配置 | 启动动画、Agent 完成通知、画布连线动画和颜色、节点菜单、画布快捷键 |
| 文本模型 | 选择对话的默认模型和分组（线路），查看可用模型 |
| 媒体模型 | 分别选择图片、视频的默认模型和分组（线路） |
| 插件市场 | 安装、配置、卸载插件，见「插件市场」一章 |
| MCP | 把麦麦工坊开放给外部 AI 工具，见「MCP 接入」一章 |
| 网络设置 | 不使用代理 / 使用系统代理 / 自定义代理，可点「测试」检查连通 |
| 设备互联 | 让手机等其他设备通过配对码或二维码连接这台电脑，可在同一 Wi-Fi 或公网使用 |
| 个性化 | 写给小麦同学的长期说明，以及本地记忆的开关、查看和删除 |
| 开发者选项 | 手动安装插件、强制安装、调试工具等，进入前需确认风险 |
| 关于 | 版本信息和检查更新 |

## 常见问题

**模型列表是空的**：先确认已登录麦麦云账号；再到「文本模型」或「媒体模型」里点刷新。

**分组（线路）是什么**：同一个模型可能有多条线路，价格、速度和稳定性不同。不确定就保持默认。

**提示词库图片、外链图片下载失败**：部分图片来自海外网站。到「网络设置」选择系统代理或填写自定义代理，再点「测试」。

**想恢复默认外观**：「界面设置」最下方有「恢复界面默认设置」。
