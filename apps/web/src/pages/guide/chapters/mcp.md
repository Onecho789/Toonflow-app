# MCP 接入

MCP（Model Context Protocol）是一种让 AI 和外部程序互相调用的通用协议。麦麦工坊支持两个方向：

| 方向 | 作用 | 入口 |
| --- | --- | --- |
| 把别人的服务接进来 | 让小麦同学使用外部 MCP 服务，如本机文件、数据库、第三方 API | 插件市场 › MCP |
| 把麦麦工坊开放出去 | 让 Claude Code、Cursor 等外部 AI 工具操作麦麦工坊的画布和项目 | 设置 › MCP |

## 一、给小麦同学接入外部 MCP

在「插件市场 › MCP」点「添加 MCP」，有三种方式：

**快速创建**：填写名称，选连接方式，再点「测试连接」确认能连上。

- 本地（stdio）：填写启动命令和参数，例如 `npx -y 某个包`
- 远程（Streamable HTTP / SSE）：填写服务地址和请求头

**从 JSON 导入**：大多数 MCP 服务的说明里都会给一段配置，直接粘贴进来，或选择 `.json` 文件。格式和 Claude Desktop、Cursor 通用：

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "D:/work"]
    },
    "remote": {
      "url": "https://example.com/mcp",
      "headers": { "Authorization": "Bearer 你的密钥" }
    }
  }
}
```

带 `url` 的按远程服务处理，带 `command` 的按本地程序处理。

**导入 DXT 包**：选择 `.dxt` 或 `.mcpb` 安装包，按提示填写所需信息即可。

导入后，启用的服务会自动变成小麦同学的工具，在对话里显示为 `[MCP: 名称]`。修改配置后，下一条消息开始生效。

> 本地 MCP 通常需要电脑上装有 Node.js（`npx`）或 Python（`uvx`），请按该服务的说明安装。

## 二、让外部 AI 工具操作麦麦工坊

适合用 Claude Code、Cursor、Codex 等编程工具批量操作画布、管理插件、读写项目文件。

1. 打开「设置 › MCP」，打开服务开关。第一次开启会自动生成访问凭证。
2. 复制客户端配置，粘贴到外部工具的 MCP 设置里：
   - **HTTP 配置**（推荐）：地址默认是 `http://127.0.0.1:10588/mcp`，带凭证请求头
   - **stdio 配置**：需要电脑上装有 Node 20 或更高版本
3. 在外部工具里让 AI 先调用 `getAppState`，确认已经连上，再开始操作。

**它能做什么**：查看和编辑画布节点、执行节点操作、管理插件和技能、操作素材库和对话、读写工作区文件和文档，还可以把任务委托给小麦同学。

**注意**：

- 服务只监听本机，外部设备连不上。
- 配置里含访问凭证，相当于一把钥匙，只交给你信任的工具。
- 操作画布、文档、切换项目时，麦麦工坊窗口要保持打开。
- 端口被占用时会自动换一个，地址变了要重新复制配置。
- 面板里还能导出「麦麦工坊 Skill」，装到外部工具里，它会更懂怎么操作麦麦工坊。
