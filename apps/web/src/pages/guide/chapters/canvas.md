# 无限画布

画布是一块可以无限拖动的白板，上面放的是一个个「节点」：文本、图片、视频、生成器……用线把它们连起来，上一个节点的结果就会变成下一个节点的输入。适合做分镜、批量出图、图生视频这类多步骤创作。

## 打开画布

左侧「无限画布」→ 新建或打开项目，就会进入工作区，默认显示画布。

- **新建画布**：点左上角的画布名称下拉 →「新增画布」。同一个下拉里还能新建文件夹、搜索画布。
- **管理画布**：画布条目右键或点「更多」，可以移动、重命名、删除。
- **删除要小心**：会同时删掉画布文件和只被它用到的素材，无法恢复。
- **保存**：自动保存，每次改动后约半秒写入磁盘，没有保存按钮。

## 添加节点

以下任意一种方式都会弹出节点菜单：

- 双击或右键画布空白处
- 点底部工具栏的「+」
- 按 Tab
- 从节点的输出端口拖一根线到空白处松手：只会列出能接上的节点，选中后自动连好

空画布中间还有「图片生成」「视频生成」「音频生成」快捷按钮。右键菜单里还可以上传文件、撤销、重做、粘贴。

## 内置节点

| 节点 | 用来做什么 |
| --- | --- |
| 文本 | 写 Markdown 文字，可以让 AI 生成或改写，常用作提示词、脚本 |
| 图片 / 视频 / 音频 | 放入你自己的素材（单个不超过 100 MB）；视频节点可截取视频帧 |
| 图片生成 | 选模型、写提示词、接参考图，点「生成图片」 |
| 视频生成 | 选模型和生成方式（文生视频、首尾帧、全能参考），点「生成视频」 |
| 音频生成 | 生成配音、音效或音乐 |
| 3D 导演台 | 用文字搭 3D 场景和运镜，导出关键帧图片或视频 |
| 逐帧拉片 | 把一段视频拆成分镜图、片段和原音轨，可选 AI 分析 |

生成过程中可以点「停止生成」。节点右上角的更多菜单里有「保存到素材库」。

## 连线规则

- 只能从**输出端**连到**输入端**，数据类型要匹配（文本接文本输入，图片接参考图……）。
- 节点不能连自己；有的节点对输入数量有限制。
- 点一下连线，会出现「断开连接」按钮。

**一个典型流程**：文本节点写提示词 → 连到图片生成 → 生成的图片再连到视频生成的首帧 → 得到一段图生视频。

## 常用快捷键

Mac 上把 Ctrl 换成 ⌘。所有快捷键都能在「设置 › 常规配置 › 画布快捷键」里修改。

| 操作 | 快捷键 |
| --- | --- |
| 添加节点 | Tab |
| 平移画布 | 按住 Space 拖动，或按 H 切到抓手 |
| 移动 / 选择工具 | V |
| 缩放 | 按住 Ctrl 滚动滚轮 |
| 适应画布 | Ctrl + 0 |
| 全选 / 取消选择 | Ctrl + A / Esc |
| 复制 / 粘贴 | Ctrl + C / Ctrl + V |
| 按住拖动复制节点 | Alt + 拖动 |
| 撤销 / 重做 | Ctrl + Z / Ctrl + Shift + Z |
| 删除 | Backspace |
| 成组 / 解组 | Ctrl + G / Ctrl + Shift + G |
| 搜索节点 | Ctrl + F |
| 整理画布 | Alt + Shift + F |

## 画布和文档

工作区顶部可以在「画布」和「文档」之间切换。文档面板左侧是「工作区文件」树，可以新建、搜索、重命名、删除文件。右键文件可「以资源管理器打开」或「在画布上聚焦」。
