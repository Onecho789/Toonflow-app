# 视频工作台

用文字或图片直接生成一段视频。左侧栏「视频工作台」或首页「生成视频」进入。用法和生图工作台类似：第一次先选一个保存作品的文件夹，作品存在其中的 `generated/` 下。

## 选择生成方式

可用的方式随模型变化，模型下方会写明它支持什么（生成方式、参考图上限、时长、分辨率、是否带音频）。

| 方式 | 适合 |
| --- | --- |
| 文生视频 | 只写文字描述，从零生成 |
| 首尾帧 | 给一张开头图（可再给一张结尾图），让画面从首帧动到尾帧 |
| 全能参考 | 给多张参考图或素材，控制角色、场景和风格 |

## 生成一段视频

1. 写提示词：描述**主体 + 动作 + 镜头运动 + 氛围**，例如“一只橘猫跳上窗台，镜头缓慢推近，午后阳光，暖色调”。
2. 按所选方式添加首帧、尾帧或参考图（支持剪贴板、上传、拖入）。
3. 设置参数：

| 参数 | 说明 |
| --- | --- |
| 比例 | 横屏 16:9、竖屏 9:16 等，或「自动」 |
| 时长 | 秒数越长越贵、越慢 |
| 分辨率 | 旁边会估算实际像素 |
| 生成音频 | 支持的模型可以同时生成声音 |

4. 点「生成视频」。视频生成通常需要几十秒到几分钟，可以先去做别的。

## 作品处理

右侧「生成结果」里可以预览、下载、加入素材库（进入「视频」文件夹）。「生成记录」可回填参数或重试失败任务。

## 小技巧

- 先在生图工作台把首帧图调满意，再用「首尾帧」生成视频，画面最可控。
- 多段视频要串成短片时，用无限画布更方便：每个镜头一个视频生成节点，统一管理。
