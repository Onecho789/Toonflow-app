### 新增

- 接入麦麦云账号：打开客户端先登录，支持邮箱验证码注册、首次登录修改初始密码；登录后自动为这台设备签发专属密钥并加密保存，退出登录即失效。网络暂时不通时可沿用本地账号进入。
- 文本、图片、视频模型统一由麦麦云提供，登录即可使用，无需自行配置供应商地址和 Key；模型下拉显示厂商图标，余额显示在画布右上角和设置的「账号」页。
- 首页改为分流页：问候与 Agent 输入框、「生成图片」「生成视频」「无限画布」三个入口，以及最近项目和最近作品；原项目列表移到「无限画布」。
- 新增生图工作台：不建项目也能出图，选择模型、比例、分辨率和参数，填写提示词与参考图后生成；一次 1–4 张，每张单独计费，失败可单张重试。参考图支持上传、拖入、粘贴，也可从作品或素材库挑选并拖动排序。
- 新增视频工作台：支持文生视频、首尾帧和全能参考三种方式（按模型能力显示），全能参考可放入图片、视频和音频素材，显示预估费用，生成中可取消。
- 工作台新增生成记录：每次生成都会记下参数与结果，可回看、回填参数或删除；刷新、切换页面或重启应用后，进行中的任务会继续查询并自动保存结果。生成结果可一键加入素材库。
- 新增云端提示词库：画布侧栏和图片、视频生成节点可浏览、搜索、筛选提示词，一键填入。
- 画布左侧新增「画布 / 资产 / 提示词库」侧栏：节点按分组树状显示，支持定位、多选、筛选和批量导出；资产页支持上传、拖入文件和插入画布。
- 图片与视频支持全屏预览：缩放、旋转、1:1 与适应窗口切换，显示尺寸和文件大小，可在多项之间切换，并可复制提示词。
- 插件市场改由麦麦云提供：登录后即可浏览、收藏和安装节点、扩展、技能与工具。
- 新增「问题反馈」页：按类型提交问题，自动附带版本与系统信息，可查看回复、继续对话和关闭工单，有新回复时侧栏显示红点。

### 优化

- 全新的麦麦工坊品牌：新 Logo、启动动画与加载页，助手更名为「小麦同学」。
- 首页背景改为星云粒子效果，项目列表与工作台使用静态星云底；侧栏选中项改为麦穗金配色。
- 工作台界面重做：参数卡片、图形化比例选择、分段选项和底部生成按钮，生成中显示占位动画与计时。
- 思考强度改为下拉选择，档位由云端模型配置决定；Agent 对话中显示运行状态，如运行中、调用工具、等待回答、出错和已完成。
- Agent 提问工具对不规范的参数更宽容，出错时给出中文提示。
- 旧对话中保存的模型选项会自动匹配到云端对应模型。

### 调整

- 移除本地模型供应商、媒体供应商和生图协议的配置功能，模型统一由麦麦云提供。
- 移除首页探索、匿名统计、赞助与交流群入口；自动检查更新暂时关闭，可在「关于」中手动检查。
