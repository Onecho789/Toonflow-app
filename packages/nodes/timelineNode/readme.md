# 成片时间线节点

把上游的视频、图片片段排成一条时间线，叠加配音或 BGM，一键合成为成片。

## 输入与输出

- 「画面片段」端口可连接多个视频、图片节点，按轨道顺序拼接。
- 「配音/BGM」端口可连接多个音频节点，从成片开头依次播放，超出成片长度的部分会被截掉。
- 合成结果写入工作区 `assets/` 目录，并在节点右侧生成新的视频节点；同一文件也会出现在本节点的「成片输出」端口，可继续连到下游节点。

## 使用方法

1. 连接视频、图片节点，片段会依次出现在画面轨道上；拖动缩略图即可调整顺序，也可以选中片段后按 Alt + 左右方向键移动。
2. 选中节点后，在下方面板点击片段：图片可设置时长（默认 3 秒），视频可设置入点和出点。
3. 上游节点带有分镜时长（`shots[].duration`，单位秒）时，会作为片段的默认时长。
4. 在下方面板调整原声和配乐的音量，点击「合成导出」，导出过程中可随时取消。
5. 点击「导出 EDL」可下载 CMX 3600 剪辑表，导入剪辑软件后重新链接素材即可继续精剪。
