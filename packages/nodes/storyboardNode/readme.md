# 分镜表节点

把剧本整理成结构化的镜头表，并为每个镜头一键创建图片生成节点。

## 输入与输出

- 输入连接文本节点，作为 AI 拆分镜头的剧本。
- 输出全部镜头的可读文本；结构化镜头保存在节点数据 `shots` 中。

## 使用方法

1. 连接剧本文本，选中节点，在下方选择文本模型后点击“AI 拆分镜头”；也可以手动新增镜头。
2. 每行可编辑景别、画面描述、台词或旁白、时长和绑定角色，拖动左侧把手调整顺序，镜号自动更新。
3. 点击“角色库”管理角色名称、设定和设定图，角色库保存在工作区的 `角色库.json`，设定图保存在 `assets/角色库/`。
4. 点击“生成画面”会在右侧创建图片生成节点，以画面描述作为提示词，并把绑定角色的设定图作为上游参考图连接过去。

AI 拆分会替换当前全部镜头。删除角色后，镜头中对它的绑定会显示为“已删除角色”。
